# entity_migration_guard.sh — intentionally migration-free entity tables.
#
# One table name (the @Table(name=...) value, or snake_case of the class name
# when @Table is absent) per line. Blank lines and lines starting with '#' are
# ignored. Adding a table here EXEMPTS that @Entity from the entity↔migration
# coverage check.
#
# IMW1-C (IDW1 dogfood closure): the guard enforces FORWARD — any NEW @Entity
# MUST ship a V*.sql migration. The 8 entities below predate the guard. They are
# classified:
#
# --- DEMO entities (permanent exempt: reference/teaching workloads, never a
#     production schema a fork-receiver ships) ---
parent
child
versioned_account
items
#
# --- DEBT (core infra tables that SHOULD have migrations; tests run on
#     ddl-auto=create-drop so the gap is invisible. Retire via IMW1-E by
#     writing V*.sql matching the entity, then deleting the line here) ---
users
refresh_tokens
verification_tokens
provider_links
