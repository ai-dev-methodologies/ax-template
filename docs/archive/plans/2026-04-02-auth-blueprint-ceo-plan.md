## Vision

### 10x Check

## Accepted Scope (added to this plan)
- 새 프로젝트용 React + Spring Boot 인증/보안 블루프린트
- 단일 블루프린트 repo 구조
- OpenAPI/Swagger 기반 계약 계층을 source of truth로 사용하고 프론트 타입/클라이언트와 연결
- 체크리스트/TODO 기반 워크플로우 검증 루프
- Plan → Validate → Execute 패턴과 실행 후 검증 루프의 결합
- 기계적으로 검증 가능한 TODO와 스크립트 중심 verify 방식
- 인증 제공자 범위: 구글 + 카카오 + 이메일
- 인증 상태 유지 방식: JWT access + refresh + HttpOnly cookie
- 3단계 검증 루프: AI 작업 중 검증 + 로컬 verify + PR/CI 검증
- 검증 전략: 실 OAuth 브라우저 E2E보다 모킹 중심 검증 우선
- 테스트 전략: unit / integration / E2E 계층 분리
- E2E 범위: 로그인, 로그아웃, 보호 라우트 접근 같은 핵심 경로만 포함
- verify 스크립트는 보안 / 계약 / 권한 위반을 즉시 실패로 처리
- RBAC 범위: admin / manager / member 3역할
- 시크릿 관리: env + 시크릿 매니저 호환
- 외부 인증 제공자 실패 시 제공자별 실패 표시 + 이메일 fallback
- 명시적 account linking 흐름
- 검증 실패 시 자동 수정 2회 후 HITL
- 토큰 만료/불일치 시 자동 refresh 1회 후 실패하면 명시 로그아웃
- refresh token rotation은 짧은 grace window + 명시 로그를 포함
- 이메일 인증 흐름: 미인증 상태 분리, 보호 기능 차단, 재발송/만료안내/idempotent 처리
- 핵심 KPI: 검증 통과율, 재작업률, 인증 구현 리드타임
- 제공자별 feature flag
- CSRF/CORS를 V1 핵심 설계에 포함
- 롤백 전략: provider flag 우선 롤백, 필요 시 전체 롤백 백업
- V1 제품 형태: forkable template repo
